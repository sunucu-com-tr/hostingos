# Screenshots · Ekran görüntüleri

Captured from a local installation with the seeded demo data
(`hostingos seed-demo`; the last one in demo mode). The interface is shown
in Turkish; every page is also available in English. Desktop screenshots
are 1440 × 900, phone screenshots 390 × 844.

Görüntüler, demo verileriyle (`hostingos seed-demo`; sonuncusu demo
modunda) yerel bir kurulumdan alındı. Arayüz Türkçe gösteriliyor; her
sayfanın İngilizcesi de var.
